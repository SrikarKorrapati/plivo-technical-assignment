# Down Memory Lane — Slack bot

@mention the bot (or DM it) with a memory like "my 5-year-old self on a beach". It replies in the
same thread with a photo of you at that age, generated by your own Flux LoRA on Replicate.

Files: `app.py` (Slack bot), `imagegen.py` (prompt builder + Replicate call), `train.py` (train your
LoRA), `generate.py` (test prompts without Slack), `manifest.yaml` (Slack app config).

## Setup

```bash
cd bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then fill in the values below as you get them
```

### 1. Train your LoRA (start this first; it takes a while)
1. Put ~20 photos of yourself in `photos/`: different settings, lighting and angles, you alone, face visible.
2. Add `REPLICATE_API_TOKEN` to `.env` (https://replicate.com/account/api-tokens; billing must be set up).
3. Start training. It creates a private model and prints a progress URL:
   ```bash
   python train.py photos/ <your-replicate-username>/down-memory-lane --trigger TOK --wait
   ```
4. When it succeeds, copy the printed `REPLICATE_MODEL=...` and `TRIGGER_WORD=...` lines into `.env`.

(You can also train on the website at replicate.com/ostris/flux-dev-lora-trainer/train. Then set
`REPLICATE_MODEL` to `owner/name:version` from your model's page.)

### 2. Tune the images (no Slack needed)
```bash
python generate.py "my 2-year-old self in my house's backyard"
python generate.py "my 5-year-old self on a beach" --lora-scale 0.8
python generate.py "my 10-year-old self in a classroom" --seed 42
```
Images are saved to `outputs/`. If the face looks too adult, lower `--lora-scale` (try 0.7–0.85).
If it stops looking like you, raise it (0.9–1.1). Put the best value in `LORA_SCALE`.

### 3. Create the Slack app
1. https://api.slack.com/apps → **Create New App** → **From a manifest** → pick your workspace → paste `manifest.yaml`.
2. **Install to Workspace** → copy the **Bot User OAuth Token** (`xoxb-…`) to `SLACK_BOT_TOKEN`.
3. **Basic Information → App-Level Tokens** → generate one with scope `connections:write` → copy (`xapp-…`) to `SLACK_APP_TOKEN`.
4. In a channel, run `/invite @Down Memory Lane`.

### 4. Run
```bash
python app.py
```
Then in Slack: `@Down Memory Lane my 5-year-old self on a beach`, or DM the bot.

## How a request flows
Slack message → `app_mention` / `message.im` event over Socket Mode → dedupe and ignore bot messages
→ ⏳ reaction and a "working on it" reply in the thread → prompt builder (trigger word + age + scene +
childhood film-photo style) → Replicate (your Flux LoRA) → image bytes → `files_upload_v2` into the
same thread → ✅ (or a friendly error and ❌).

The bot runs on your machine and only works while `python app.py` is running.
